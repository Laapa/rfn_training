# Тренировка резонаторов — заметки для ассистента

Перед работой прочитай **docs/HANDOFF.md** — там полное состояние проекта: цель, окружение пользователя,
атрибуты стенда, решения по алгоритму, архитектура, история дизайна, Taurus, фейковый стенд,
что проверено и что нет, открытые вопросы и договорённости.

Коротко: PyQt5 + pyqtgraph + Taurus (только показ) + PyTango 9.5.1 (Python 3.12, Windows у пользователя);
алгоритм в trainer/core.py; окно резонатора gui/panel.py; фейковый стенд fake_server/ (своя база Tango, PyTango 10.3.2).
Отвечать по-русски. Ветка claude/busy-cannon-llmzmp, коммитить и пушить после каждого шага.
Старые skif.py, dio.py, config.json, ui/skif.ui — образец, не трогать.
