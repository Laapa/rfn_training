# Тренировка резонаторов — ТЗ (рабочее)

## Что делаем
Программа на PyQt5 + PyTango для тренировки нескольких резонаторов одновременно.
У каждого резонатора свой режим MANUAL/AUTO и свои настройки. Запуск — exe (PyInstaller).

## Слои
| Папка | Что | Зависит от |
|---|---|---|
| `trainer/core.py` | алгоритм тренировки (автомат состояний) | ничего |
| `trainer/sim.py`  | симулятор резонатора | ничего |
| `trainer/tango_res.py` | резонатор через Tango: `<prefix>/mod`, `cav`, `sspa` (prefix из config, напр. `rf2/1e2`) | PyTango 9.5.1 (стенд — Tango 9.3.4, ПК — Python 3.12) |
| `gui/` | окно «Обзор» (таблица, галка = показать окно резонатора) + отдельное окно на каждый резонатор в пол-экрана | PyQt5, pyqtgraph |

| `trainer/config.py`, `trainer/datafile.py` | настройки (training_config.json), запись .dat и журнала .log | ничего |
| `fake_server/fake_rf.py` | фейковый стенд: mod/cav/sspa с «физикой», без базы Tango | PyTango |
| `training.spec`, `build_exe.bat` | сборка Training.exe (PyInstaller) | PyInstaller |

## Алгоритм (решения)
- Шаг каждые Response Delay, только когда вакуум ≤ Good.
- Между Good и Bad новый отсчёт не начинается — ждём Good.
- Во время отсчёта стало ≥ Bad — отсчёт сбрасывается, ждём Good.
- ≥ Very Bad в любой момент — сразу 3 шага назад (настраивается).
  Дальше: стал Good — идём вперёд (через Response Delay);
  за Timeout так и не стал Good — ещё 3 шага назад, и так вплоть до Start.
- Start/Stop не вводятся, а вычисляются из Low/High и направления.
- Старт с текущей уставки. Если уставка уже на Stop или за ним — не запускаемся.
- UP/DOWN: дошли до Stop — галка снимается, MANUAL, фанфары.
- ZONE: дошли до края — разворот, бесконечно.
- SAW (пила): плавно Low → High, на High одна выдержка, резко в Low, снова вверх; бесконечно.
- Ток фидера — отдельная уставка, общая для ручного и AUTO; алгоритм её не трогает.
- Шагаем и сравниваем по **уставке** напряжения (кВ). Измеренные U пишем в лог.
- Настройки можно менять на ходу; если Stop оказался позади — считаем, что дошли.

## Железо (из старого skif.py) — основа для своих device-серверов
| Канал | Что | Пересчёт |
|---|---|---|
| ai0 | I фидера | × i_coeff (45) → А |
| ai1 | U резонатора | × u_adc_coeff (282) → кВ |
| ai3 | Фазометр | / 0.05 → град |
| ai4 / ai5 | Падающая / отражённая | полиномы for_pad / for_otr → кВт |
| ai6 / ai7 | Готовность / АРУ | > 1.5 В / > 3.5 В |
| ao0 / ao1 | Уставка U / I | кВ / u_dac_coeff (187), пишется со знаком минус; А / 29 |
| DO line0,1,2,4 | Сброс ГЕН, Сброс ББ, Выкл МОД, Вкл МОД | импульс 1 с |
| Modbus 10.0.0.96:502 unit 3, reg 1 | ток насоса | Торр = А / vac_coeff |

## Стенд (ответы)
- Устройства: `<prefix>/mod`, `cav`, `sspa`; prefix у резонаторов отличается цифрами (rf2/1e2 ...).
- `cav/Vac` — в торрах. Фазометра нет, сброс один — `RstAll`.
- Tango на стенде 9.3.4; на ПК Python 3.12 -> PyTango 9.5.1.
