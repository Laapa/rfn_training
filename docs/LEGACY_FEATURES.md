# Всё, что умела старая программа (skif.py) — и где это в новой

Правило: **ничего не убираем, только добавляем.** Каждая строка ниже должна в итоге
получить статус ✅. Всё, что было у одного резонатора, в новой программе есть
**у каждого** резонатора (в его окне).

Статусы:
✅ уже есть · 🔜 делаем без железа · ⏳ ждёт описания атрибутов Tango ·
⚠️ в старой проге было не подключено (кнопка/поле ничего не делали) — решить, что с ним
