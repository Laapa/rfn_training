# Тренировка резонаторов

Программа автоматической и ручной тренировки ВЧ-резонаторов через Tango.
Несколько резонаторов одновременно, у каждого своё окно («Главная» старой программы).
Алгоритм — в `docs/SPEC.md`, что перенесено из старой программы — в `docs/LEGACY_FEATURES.md`.

## Установка (Windows, Python 3.12)

```
pip install -r requirements.txt
```

## Запуск

```
python main.py                      настройки из training_config.json
python main.py fake_config.json     другой файл настроек
```

При первом запуске создаётся `training_config.json`. В нём список резонаторов:

```json
{"name": "Резонатор 1", "type": "tango", "prefix": "rf2/1e2"}
```

- `type`: `"sim"` — встроенный симулятор, `"tango"` — резонатор через Tango
  (устройства `prefix/mod`, `prefix/cav`, `prefix/sspa`);
- `tango_host` — адрес базы Tango, если не задана переменная окружения `TANGO_HOST`;
- `tick_ms` — период работы алгоритма (1000 = раз в секунду);
- `settings` у резонатора программа заполняет сама (Low, High, пороги...), их не трогать.

Данные пишутся в `data/<резонатор>/ГГГГ-ММ-ДД@ЧЧ-ММ-СС.dat`, рядом — журнал событий `.log`.

## Проверка на фейковом стенде (без железа)

1. В одном окне запустить фейковый стенд и не закрывать:
   ```
   python fake_server/fake_rf.py
   ```
   Он поднимает `rf2/1e2`, `rf3/1e3`, `rf4/1e4` (mod, cav, sspa) без базы Tango
   и создаёт `fake_config.json`.
2. Во втором окне — программа:
   ```
   python main.py fake_config.json
   ```

Что проверить:

| Проверка | Как |
|---|---|
| Значения и лампочки | MANUAL, задать U и I — «Данные» и графики следуют за ними |
| Тренировка | AUTO, U MIN 5, U MAX 15, Response Delay 2 — шагает, на пробоях откатывается на 3 шага |
| Блокировка | при сильном пробое гаснет «Готовность», U падает в 0; «Сброс», потом «Вкл МОД» |
| Обрыв связи | закрыть фейковый стенд (Ctrl+C) — AUTO выключается, в «Данных» прочерки |
| Сохранение настроек | закрыть программу, открыть снова — Low/High/пороги на месте |

Резонаторы стенда «чистые» до 8 / 11 / 14 кВ — выше начинаются пробои.

## Сборка exe

На Windows:

```
build_exe.bat
```

Результат — папка `dist\Training` с `Training.exe` (копировать папку целиком).
`training_config.json` и `data` создаются рядом с exe.
