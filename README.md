# Тренировка резонаторов

Программа автоматической и ручной тренировки ВЧ-резонаторов через Tango.
Несколько резонаторов одновременно, у каждого своё окно («Главная» старой программы).
Алгоритм — в `docs/SPEC.md`, что перенесено из старой программы — в `docs/LEGACY_FEATURES.md`.

## Установка (Windows, Python 3.12)

```
pip install -r requirements.txt
```

## Запуск

```
python main.py                      настройки из training_config.json
python main.py fake_config.json     другой файл настроек
```

При первом запуске создаётся `training_config.json`. В нём список резонаторов:

```json
{"name": "Резонатор 1", "type": "tango", "prefix": "rf2/1e2"}
```

- `type`: `"sim"` — встроенный симулятор, `"tango"` — резонатор через Tango
  (устройства `prefix/mod`, `prefix/cav`, `prefix/sspa`);
- `tango_host` — адрес базы Tango, если не задана переменная окружения `TANGO_HOST`;
- `tick_ms` — период работы алгоритма (1000 = раз в секунду);
- `settings` у резонатора программа заполняет сама (Low, High, пороги...), их не трогать.

Данные пишутся в `data/<резонатор>/ГГГГ-ММ-ДД@ЧЧ-ММ-СС.dat`, рядом — журнал событий `.log`.
Посмотреть запись: кнопка «Просмотр записей…» в окне «Обзор» —
три графика с выбором величины и журнал; щелчок по строке журнала отмечает момент на графиках.

Автомат сам стоит, пока нет «Готовности» (ВЧ выключено или сработала блокировка):
уставку не трогает, после «Сброс» + «Вкл МОД» продолжает с ожидания Good.

## Проверка на фейковом стенде (без железа)

Фейковый стенд поднимает **свою маленькую базу Tango** (SQLite) и в ней устройства
`rf2/1e2`, `rf3/1e3`, `rf4/1e4` (mod, cav, sspa) — с теми же атрибутами и командами, что на стенде.
Программа, Taurus и Jive видят их по обычным именам через `TANGO_HOST=127.0.0.1:10123`.
Вашу настоящую базу Tango он не трогает.

1. Окно 1 — стенд (не закрывать). Проще всего двойным щелчком по `fake_server\start_fake.bat`
   или из терминала:
   ```
   fake_server\start_fake.bat
   ```
   При первом запуске создаётся отдельное окружение `.venv_fake` с PyTango 10
   (встроенная база Tango есть только в нём; программа остаётся на PyTango 9.5.1).
   Стенд создаёт/обновляет `fake_config.json`.
2. Окно 2 — программа:
   ```
   .\.venv\Scripts\Activate.ps1
   python main.py fake_config.json
   ```

Что проверить:

| Проверка | Как |
|---|---|
| Значения и лампы | MANUAL, «уставка U» и «уставка I» (−/+ или ввод + Enter) — значения, лампы и графики следуют |
| Тренировка | Umin 5, Umax 15, dt 2, метод «Вверх», галка AUTO — шагает, на пробоях откатывается на 3 шага |
| Готовность | в AUTO кнопка «Выкл» — автомат встаёт («Нет готовности, ждём»); «Вкл» — продолжает |
| Авария | сильный пробой — лампа «Авария» красная; когда вакуум откачается: «Сброс», потом «Вкл» |
| Нет стенда | программа всё равно открывается: прочерки, «Авария» (наведи мышь — причина); ошибки — в error.log рядом с настройками |
| Обрыв связи | закрыть фейковый стенд (Ctrl+C) — AUTO выключается, в «Данных» прочерки |
| Сохранение настроек | закрыть программу, открыть снова — Low/High/пороги на месте |

Резонаторы стенда «чистые» до 8 / 11 / 14 кВ — выше начинаются пробои.

## EPICS (вместо или вместе с Tango)

Резонатор с `"type": "epics"` работает через EPICS Channel Access (`pyepics`, библиотека CA уже внутри —
ставить EPICS не нужно). Имена PV — по шаблону `<prefix>:<MOD|CAV|SSPA>:<имя>`, как атрибуты Tango:
`RF2:MOD:Ucav`, `RF2:MOD:UcavSetpoint`, `RF2:CAV:Vac`, `RF2:SSPA:SspaPforw`…; команды — запись 1 в
`RF2:MOD:ModOn` / `ModOff` / `RstAll`; лампы «Вкл»/«Авария» — `RF2:MOD:RfOn` / `RF2:MOD:Fault`.
Настоящие имена стенда пока неизвестны — любое имя заменяется в config:

```json
"epics_ca_addr_list": "10.0.0.5",
"resonators": [
    {"name": "Резонатор 2", "type": "epics", "prefix": "RF2",
     "pv": {"Ucav": "RF2:CAV:Voltage", "RfOn": null, "Fault": null}}
]
```
`null` — такого PV на стенде нет («Вкл» тогда берётся из «Готовности», «Авария» — только по связи).
`epics_ca_addr_list` — адреса IOC (или CA gateway); пусто — обычный поиск EPICS в своей подсети.
Значения и лампы EPICS-резонатора показываются обычными полями (без Taurus).

Фейковый EPICS-стенд (IOC на `caproto`, только на этом компьютере), два окна:
```
fake_server\start_fake_epics.bat
python main.py fake_epics_config.json
```
Пробой вручную: `python fake_server\spike_epics.py RF2`. Проверки — те же, что для Tango-фейка.

## Сборка exe

На Windows:

```
build_exe.bat
```

Собирает окружением `.venv` (PyInstaller ставит туда сам). Результат — папка `dist\Training`
с `Training.exe` (копировать папку целиком). `training_config.json` и `data` создаются рядом с exe.

Проверить exe на фейковом стенде (фейк запущен):
```
cd dist\Training
.\Training.exe ..\..\fake_config.json
```
